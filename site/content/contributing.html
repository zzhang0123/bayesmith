Build and verify the documentation

python3 tools/build_docs.py
python3 tools/build_docs.py --check
node tools/check_docs_math.cjs

The builder uses only Python's standard library. It checks source exports, links, anchors and stale generated output. The Node check renders every inventoried formula using the vendored KaTeX engine. Content lives under site/content/, navigation in site/navigation.json, examples in site/snippets/. API pages are generated from source signatures and docstrings without importing the package.

Build success does not execute numerical examples or establish browser accessibility. Run downloadable tutorials in a suitable environment, then inspect navigation, search, focus, theme and small-screen overflow separately.

Review by independent responsibility

Architecture review checks dependencies and ownership. Numerical review checks estimands, support, normalization and failure behavior. API review checks shapes, compatibility and provenance. Packaging review checks the installed artifact and shipped resources. Documentation review follows a real reader from installation to interpretation. Resolve findings, rerun affected checks and have the revised result reviewed again.
