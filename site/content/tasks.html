Compilation and execution can return Refusal. Check both boundaries before consuming the result. A numerical execution failure can raise an exception; it is not a statistical conclusion about the model.

Understand the references

A predictive task stores a reference to its source posterior; execution receives the actual posterior separately. Results and provenance explains identity checks and reuse.

The point task requests POSTERIOR_MEAN. Changing it to MAP changes the estimand even when both coincide in this symmetric Gaussian example. The simulation task draws from the prior; it does not reuse the posterior unless you declare that parameter source.

Supported models

These five tasks work on this deliberately simple graph. General posterior sampling has wider support than replicated prediction, and whole-graph analytic evidence has stronger normalization and structure requirements than posterior sampling. A successful Gaussian tutorial does not certify arbitrary graphs.
