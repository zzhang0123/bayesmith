Install the numerical runtime, then make precision and optional integrations explicit.

Install 0.10

From the package index:

python -m pip install "bayesmith==0.10.0"

python -m pip install bayesmith installs the latest release the index carries, whose capabilities may differ from this documentation.

Python 3.11 or newer is declared by the package. Runtime dependencies are JAX, Equinox, NumPy and NumPyro. Device support is determined by your JAX installation; bayesmith does not install or configure a GPU driver.

Check your installed version with:

python -c "from importlib.metadata import version; print(version('bayesmith'))"

0.10 retains the 0.9 baseline requirement of NumPyro below 0.22 and is verified with 0.21. NumPyro 0.22 changes argument validation and Gibbs dynamic-support behavior; supporting it requires a separate compatibility update.

Use the current source

git clone https://github.com/zzhang0123/bayesmith.git
cd bayesmith
uv venv --python 3.12
uv pip install -e . --group dev

The editable installation follows source changes. Distribution metadata can lag until you reinstall; use pyproject.toml for the checkout's declared version. Development uses the project-local tools under .venv/bin/.

Choose precision before starting JAX

JAX_ENABLE_X64=1 python five_tasks.py

Use a fresh process for precision-sensitive evidence calculations. bayesmith does not change JAX's global precision setting on import. Float32 is usable for admitted routes, but the analytic evidence task explicitly requires x64. A precision refusal describes an unmet numerical premise; rerun with the required precision rather than removing the guard.
