A Graph defines a joint probability law through conditional distributions and deterministic transformations.

From population to observations

A population parameter can govern several latent variables; deterministic operators map those variables into predicted signals; observation distributions connect the signals to measured data. Hierarchy lives in these conditional dependencies. Constants and deterministic nodes participate in the calculation without adding a sampled coordinate of their own.

Normal distributions below use variance as their second mathematical parameter; the Python API uses standard deviation.

\begin{aligned}\theta&\sim\mathcal{N}(0,2^2),\\z_i\mid\theta&\sim\mathcal{N}(\theta,0.5^2)\end{aligned}
s_i=2z_i,\qquad y_i\mid z_i\sim\mathcal{N}(s_i,0.2^2)

Joint density

For this model, with fixed noise scales and observations y, the ordinary site factors give:

p(\theta,\mathbf z,\mathbf y)=p(\theta)\prod_{i=1}^{N}p(z_i\mid\theta)\,p(y_i\mid 2z_i)

The deterministic signal is substituted into the likelihood. The posterior conditions this same joint model on y; it does not reverse the declared arrows. General graphs may have multiple parents and richer dependence than this simple chain.

This executable example compares log_joint with an independent Gaussian calculation. log_joint returns the joint log-density at the supplied latent values and observed data; it is not a normalized posterior density.

Node roles

DeclarationRole
constFixed input with a graph identity.
detDeterministic function of named parents.
sampleLatent random variable with a conditional distribution.
observeDistribution conditioned on observations.
joint_priorAn explicit graph-level prior factor coupling named latent sites.

Declare these inside the function passed to trace. Tracing executes the declaration once to build a static directed acyclic graph; it does not draw a simulated dataset. Declare parents before their children. Parent arguments are node references. Distribution constructors and numerical operations run inside the attached callables. Model changes should produce a newly traced graph and fresh fingerprints.

joint_prior adds a factor to the site contributions; it does not automatically replace their priors. Use flat site measures for covered latents when the graph-level factor supplies their prior, and respect that prior object's contract. Ordinary conditional hierarchies such as the example above need no joint_prior.

Separate batch, event and draw axes

NumPyro distributions distinguish batch shape from event shape. A vector of independent normal observations and one multivariate-normal observation may have the same visible array shape but different density grouping and covariance semantics. Use .to_event(...) only when the model needs that event interpretation.

plate declarations record a named repetition axis; they do not justify treating dependent data as independent. The current Graph supports at most one plate per node, without nested plates. Units may be conditionally independent given a population parameter while remaining marginally correlated through that shared parameter. Posterior and artifact arrays have additional sample axes. Read each NamedArray's dimensions and method contract before flattening chain and draw axes.

Represent missing observations with masks

bs.observe(
    "signal", lambda x: dist.Normal(x, 0.5), level,
    obs=jnp.array([0.8, 0.0, 1.2]),
    mask=jnp.array([True, False, True]),
)

True means the sample was observed. Supply a boolean mask shaped like the observation. The finite placeholder at a masked entry is not data used in the likelihood. Do not replace a missing measurement by infinite noise or introduce NaNs into intermediate calculations.

Changing data or masks changes the conditioning fingerprint. A posterior fitted under an old mask is not interchangeable with a new fit. Held-out checks use the distinction between included and withheld observations.

Structural declarations

Automatic affinity analysis can certify supported affine computations. A user declaration alone must not make a nonlinear model exact. Gaussian prior eligibility and covariance dependence are checked separately from the mean's affinity. Unsupported operations or derivative semantics can leave a claim unresolved.

For correlated noise, declare its probability law rather than hiding its covariance in a scale vector. For complex variables, consult {{api:bayesmith:ComplexNormal}} and its real-coordinate convention. Continue with route eligibility.
