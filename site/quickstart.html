Example 01 · Your first posterior

Start here after installation: this first tutorial teaches the complete declare → compile → sample → check loop. Infer one latent level from three measurements. The whole model is one exact block, so the posterior draws are independent and exact.

  1. ModelPrior · likelihood
  2. DataThree measurements

Model

A sample node contributes a prior. An observe node contributes a likelihood and attaches data. Parent references express dependencies; ordinary JAX operations live inside the functions attached to nodes.

Complete runnable script
first_model.py
"""Run with: python first_model.py"""

import jax
import jax.numpy as jnp
import numpyro.distributions as dist

import bayesmith as bs

DATA = jnp.array([0.8, 1.0, 1.2])


def model(data):
    level = bs.sample("level", lambda: dist.Normal(0.0, 2.0))
    bs.observe("signal", lambda x: dist.Normal(x, 0.5), level, obs=data)


def main():
    graph = bs.trace(model, DATA)
    plan = bs.compile(graph)
    print(plan)
    posterior = plan.sample(jax.random.key(7), num_samples=256)
    print("Posterior sample shape:", posterior.samples["level"].shape)
    print("Posterior mean estimate:", posterior.samples["level"].mean())
    return posterior


if __name__ == "__main__":
    main()

Data

Three measurements of one level, 0.8, 1.0 and 1.2, each with known noise standard deviation 0.5. The prior on the level is Normal with mean 0 and standard deviation 2.

Infer

Read the plan before the samples:

The prior is Normal, the prediction is the level itself and the noise is fixed, so the whole graph is one exact block. The execution line says each draw is independent and exact: there is no chain, no warmup and no convergence to diagnose.

See the posterior

Check

This model has a closed-form posterior. With prior standard deviation 2 and measurement standard deviation 0.5:

\sigma_{\mathrm{post}}^2=\left(\frac{1}{2^2}+\frac{3}{0.5^2}\right)^{-1}=\frac{1}{12.25}
\mu_{\mathrm{post}}=\sigma_{\mathrm{post}}^2\frac{0.8+1.0+1.2}{0.5^2}=\frac{12}{12.25}\approx0.9796

The mean of 256 independent draws differs from 0.9796 by Monte Carlo error with standard deviation \sigma_{\mathrm{post}}/\sqrt{256}\approx0.018.
