API reference

Find an entry point by responsibility, then inspect its source-derived contract. Every declared public export is checked during the build.

Names in __all__ are explicit exports; for modules without it, public source definitions are included for discoverability. Re-exports retain their defining module. Class fields are local declarations; inherited fields and runtime-generated constructors are not expanded. Inclusion is not a separate stability promise. Runtime, backend-specific, experimental and deprecated surfaces keep their documented limits.

Recommended entry points

Begin with the facade that owns your question; the exhaustive module catalog follows.

  • bayesmith: tracing, graph declarations, compilation and execution.
  • bayesmith.artifacts: task/result types, policies and serialization.
  • bayesmith.evaluation: model checks and report aggregation.
  • bayesmith.exact: exact numerical primitives.
  • bayesmith.marginal: nuisance-integrated likelihood components.
