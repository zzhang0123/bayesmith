## Survivor cluster A — every conditioned latent has exactly one parent (K1)

**M01, M02b.** `conditional_prior_range_report` pins **one parent at a time**
and puts every other latent at its prior centre. No fixture has a conditional
with two parents, so nothing separates "pin the parents that matter" from "pin
one and hope".

**Built as a bypass and run.** Two graphs, identical except for how the same
fault is expressed:

```python
# B1  — the width is infinite only where BOTH taus are low
w = det("w", lambda a, b: jnp.where((a < 1.0) & (b < 1.0), jnp.inf, 1.0), t1, t2)
# B1b — the same fault, one parent
w = det("w", lambda a: jnp.where(a < 1.0, jnp.inf, 1.0), t1)
```

| | B1b (one parent) | B1 (two parents) |
|---|---|---|
| `at_points` | `{'t1': [0.5, 1.5, 2.5, 3.5]}` | `{'t1': [0.5,1.5,2.5,3.5], 't2': [0.5,1.5,2.5,3.5]}` |
| `report.degenerate` | `(('x','t1',0.5,'unverifiable'),)` | **`()`** |
| `compile_task` premise | `evidence_conditional_prior_proper` | **`capability_unavailable_r1`** |

The corner is not outside the grid and not between its points — `t1 = 0.5` and
`t2 = 0.5` are both listed in `at_points`. It carries prior mass
**5.18e-04** under `N(2,0.5)²`, and `marginal_log_density` there returns
exactly **`-inf`**, which is the failure mode the author's own
`test_today_the_collapse_guard_does_not_fire_on_this_at_all` pins as the reason
this check has to exist. `conditional_prior_verdicts(graph, {t1: 0.5, t2: 0.5})`
answers `unverifiable` — the machinery can see it; the sweep never asks.

The docstring's disclosure covers "a degeneracy strictly between the grid's
points, or outside its ends". This is neither.

## Survivor cluster B — every swept parent is a root `Normal` (K11)

**M11.** `_probe_values` returns `None` for any parent whose prior is not
Gaussian, and `conditional_prior_range_report` then `continue`s: the parent is
neither swept nor recorded. Measured over 60 shipped graphs, that branch is
taken **zero** times, because every parent any conditional depends on is a root
`Normal`.

**Built as a bypass and run.** The same `jnp.where(t > 1.0, 1.0, jnp.inf)`
conditional under five hyperpriors:

| hyperprior on `tau` | `at_points` | `degenerate` | premise |
|---|---|---|---|
| `Normal(2, 0.5)` | `{'tau': [0.5,1.5,2.5,3.5]}` | 1 cell | `evidence_conditional_prior_proper` |
| `StudentT(4, 2, 0.5)` | `{}` | `()` | **`capability_unavailable_r1`** |
| `Laplace(2, 0.5)` | `{}` | `()` | **`capability_unavailable_r1`** |
| `Uniform(0, 4)` | `{}` | `()` | **`capability_unavailable_r1`** |
| `LogNormal(0.7, 0.3)` | `{}` | `()` | **`capability_unavailable_r1`** |

`_probe_values` was measured directly and returns `None` for **StudentT,
Laplace, Uniform, LogNormal and Cauchy**, and a grid only for `Normal`.

For the StudentT case the corner carries prior mass **0.058** — a sixteenth of
the prior, not a corner — and `marginal_log_density` at `tau = 0.5` is exactly
`-inf`. The refusal that is issued says, verbatim:

> this graph's evidence is admitted: its priors are proper, **its conditionals
> are densities across the range the integral covers**, and [] collapses
> exactly.

Zero points were evaluated. `at_points` is `{}`. This is the same disease
`CLAUDE.md` records twice under "a result that cannot distinguish the thing it
names from a thing that merely resembles it": the report cannot tell "nothing
was found" from "there was no grid", and the message it feeds asserts the first.

## Survivor cluster C — the degeneracy is always an infinite width (K9)

**M06.** `if verdict is not PriorVerdict.PROPER` was narrowed to
`if verdict is PriorVerdict.UNVERIFIABLE`, and nothing noticed, because the
only degenerate conditional any test builds is an infinite `Normal` width,
which audits as `UNVERIFIABLE`. Its sibling M05 (narrow to `IMPROPER`) is
KILLED, so the pair measures exactly which half is exercised.

**Built as a bypass and run.** A conditional that is `Normal(0,1)` above a cut
in `tau` and a flat improper density below it audits as **`improper`**, and the
real code catches it (`degenerate = (('x','tau',0.5,'improper'),)`,
`evidence_conditional_prior_proper`). Under M06 it is dropped. The verdict arm
is therefore live code with no test behind it.

## Survivor cluster D — one degenerate cell, one swept parent (K7, K10)

## Survivor H — the option arm's position in the chain is unobservable (M19)

`_evidence_route_refusal`'s docstring states a four-step order: structure, then
options, then conditional propriety, then capability. **The middle boundary
cannot be observed.** `_evidence_option_refusal` returns `None` whenever
`residual` is true, and both later premises run only when `residual` is true —
so no graph exists on which the option arm and the conditional arm are
simultaneously false. Swapping them (M19) changes nothing.

The other boundaries were checked by construction and all hold:

| prior audit + degenerate conditional | `evidence_prior_proper` | precompile first ✔ |
| method row + degenerate conditional (`gcr+mh` corner graph) | `evidence_residual_method_unsupported` | structure first ✔ |

## Findings that are not mutants

1. **`evidence_prior_proper` refuses every plated hierarchical model.** A
   conditional with an event shape audits `UNVERIFIABLE`. Not asserted
   anywhere.

2. **The `_RESIDUAL_METHODS_REFUSED` comment states a property the code does
   not have.** It says a third method arriving "is a KeyError-shaped omission
   rather than a silent admission". Built and run with a stub plan carrying
   `method="gcr+newthing"` and a non-empty sampled block:
   `_evidence_structure_refusal` returns **`None`** and the route reaches
   `capability_unavailable_r1`. A `frozenset` membership test cannot raise
   `KeyError`. Not live today (only three methods are emitted), but once
   `residual_backend()` returns a backend, a fourth method would be silently
   admitted — which is what the comment says is impossible.

3. **`ConditionalPriorRange` is the only one of 73 registered artifact types
   carrying a mutable container field.** `_codec.register_artifact_type`'s own
   docstring: *"A mutable dataclass is refused because an artifact that can be
   edited after its fingerprint was taken is not an identity."* The guard reads
   `__dataclass_params__.frozen` — a spelling — and `at_points: dict[...]` walks
   past it. Measured: `r.at_points["tau"] = (99.0,)` mutates a frozen instance,
   and the class is the only registered artifact that is unhashable.

4. **"the six latents that have parents" is seven.** Stated twice in the commit
   message and once in `audit_graph_priors`'s docstring. Measured over the
   test's own `_shipped_graphs()` helper (54 graphs): **6 graphs, 7 latents** —
   `three_latent_chain` carries two (`x` and `y`). The test asserts over graph
   names and is green; only the prose is wrong.

5. **`evidence_residual_integral_required`'s message can be false of a graph
   that reaches it.** Its Finding says "this graph declares no latent
   parameter", but the branch is `if not sampled:` — reached by any graph with
   an exact block, no sampled block, and a method outside `{"gcr"}` and
   `_RESIDUAL_METHODS_REFUSED`. Confirmed with a stub plan. Latent, not live.

6. **A location-driven degeneracy fails differently.** With the parent driving
   the conditional's MEAN to infinity, `marginal_log_density` returns **`nan`**
   rather than `-inf`. The range check catches it (so the "read the density,
   not a coordinate" design holds), but the plan's and the commit's account of
   the downstream symptom names only `-inf`.
