# P1 — 两块 latent 的局部耦合

**日期**：2026-08-29  
**状态**：已实现  
**实现**：`src/bayesmith/diagnose/coupling.py`  
**探针**：`docs/probes/probe_19_coupling_oracles.py`

## 一、问题与公开接口

`block_coupling(graph, first, second, *, at)` 在调用者给出的点上，把两组
latent 一起线性化，返回：

1. 全部典型相关及其最大值的三值裁决；
2. 条件块 NUTS 的 `κ_cond`；
3. 边缘化目标的 `κ_marg`；
4. 联合 NUTS 的 `κ_joint`。

`at` 是必需参数。这里不猜初值、不求 MAP，也不把一个局部量冒充全局量。报告是
持有 NumPy 数组的 frozen dataclass；`correlation` 只能是
`Measured(value, floor, n_eff)`、`Refused(reason)` 或
`NotApplicable(reason)`，没有裸 float，也没有 `low` 这一种会把数值噪声写成科学结论
的裁决。每份报告明带 `blind_to=("gaussian-only",)`。

## 二、为什么是典型相关，不是逐元素相关

对两块变量 `u`、`v`，第一典型相关是

```text
c₁ = max_{a,b} corr(aᵀu, bᵀv).
```

它在每块允许任意线性组合。高维脊常是“所有增益一起上浮、所有像素一起下沉”，没有
任何一个坐标对必须高度相关；逐元素相关会漏掉这条方向，典型相关不会。

两块高斯 Gibbs 的转移算子非平凡特征值是 `{cᵢ²}`，所以最慢方向的谱隙为
`1-c₁²`，积分自相关时间为

```text
τ(c) = (1+c²)/(1-c²).
```

这个收费与 HMC 的收费有一个中心不对称。把标准化二元高斯的椭圆条件数写成

```text
κ = (1+c)/(1-c),       c = (κ-1)/(κ+1),
```

代回可得

```text
τ(c) = (κ + κ⁻¹)/2  ~ κ/2.
```

所以块 Gibbs 沿最慢方向付的是对 `κ` 的**线性**收费。HMC 的稳定步长受最硬方向约束，
`ε ≲ 1/sqrt(λ_max)`；走过最软方向的典型距离需要 `sqrt(λ_max/λ_min)=sqrt(κ)`
个步长，因此是 **`sqrt(κ)` 平方根收费**。这就是强耦合时“平方根对一次方”的损失，
而不是一句经验性的“相关可能让链慢”。

## 三、HGR 最大相关，以及只漏报不误报

真正控制一般两块 Gibbs 的量是 Hirschfeld–Gebelein–Rényi 最大相关

```text
ρ* = sup corr(f(u), g(v)),
```

上确界取遍平方可积的 `f`、`g`。Lancaster 定理说明：联合高斯时上确界在线性函数
取得，故 `ρ*=c₁`。非高斯时线性函数仍属于这个函数类，所以恒有 `ρ*≥c₁`，而且可以
严格大于。

因此，在数值地板以上，线性 CCA 报告高耦合时，HGR 耦合只可能更高；它不会凭空制造
一条不存在的高耦合。这是一条**单边性质**：线性 CCA 只会漏报，绝不会误报。反方向
不成立——低 `c₁` 绝不构成低 `ρ*` 的证书。

## 四、算法：只走分块精度

局部 Fisher 信息加声明先验精度为

```text
F = [[F_xx, F_xθ],
     [F_θx, F_θθ]].
```

实现取 `L_x L_xᵀ=F_xx`、`L_θ L_θᵀ=F_θθ`，用两次三角求解构造

```text
M = L_x⁻¹ F_xθ L_θ⁻ᵀ,
```

再对 `M` 做 SVD。它从不形成 `F⁻¹`。这既避免把条件数从 `sqrt(κ)` 放大为 `κ`，也
无需支付协方差路径的 `condition_ceiling` 拒绝。M6 的独立 oracle 故意走相反路线：
NumPy `inv(F)` 后从协方差块白化；本 fixture 全谱最大差 `3.33e-16`，计划原始三次
实测最大差 `1.1e-16`。

三个条件数直接量：

```text
κ_cond  = κ(F_θθ)
κ_marg  = κ(L_θ (I-MᵀM) L_θᵀ)
κ_joint = κ(F)
```

特别地，`κ_marg` 不是 `c₁` 的函数。M5 在同一个 `c=.99` 下给出：

| `F_θθ` | 实测 `κ_marg` | 错公式 `κ(F_θθ)/(1-c²)` |
|---|---:|---:|
| `diag(1,100)` | 5025.1256 | 5025.1256 |
| `diag(100,1)` | 1.99 | 5025.1256 |

只钉第一格会让错公式永久存活；测试与 probe 同时钉两格。

数值地板是

```text
floor_c = sqrt(κ(F_xx) κ(F_θθ)) eps.
```

`c≤floor_c` 是 `Refused`，不是 `low`。闭边界有直接测试，因此把 `<=` 误改成 `<`
会红。

## 五、M1：为什么没有廉价可分性证书

反例是 20 个观测的

```text
x ~ Normal(0, 10)
θ ~ Normal(0, 1)
μ = x 1₂₀ + exp(θ)
σ = 0.5
data = 4 + 0.5 * default_rng(0).normal(size=20)
```

在后验众数，`max|∂²μ/∂x∂θ|=0.0` **逐位为零**；噪声不随参数移动，故
`sigma_movement=0.000e+00`。若证书问“`θ` 是否进入 `x` 的设计矩阵”，它会宣布可分。

但真正的问题是 `∂μ/∂θ` 在 `range(∂μ/∂x)` 里有多少。这里

```text
∂μ/∂x = 1₂₀,
∂μ/∂θ = exp(θ) 1₂₀,
```

二者完全共线：`x` 的上移可由 `exp(θ)` 的下移抵消。独立的精确 observed-Hessian
oracle 给相关 **−0.9942708160481082**；Fisher/Laplace 路给
**−0.9940992046901365**（模块报告其非负典型相关 0.9940992046901365），对应
`τ≈174`。所以混合二阶导为零没有排除任何危险耦合；本模块明确**没有**廉价可分性
阶段。

## 六、盲区

Laplace/CCA 是一个点的一阶、二阶局部量：换一个 mode 会换答案，多峰后验甚至没有
一个局部报告能代表全局混合。尺度型依赖更坏。Neal funnel 的众数处 Laplace 相关
**精确 0.0**；20 万 iid 样本上线性特征 CCA 是 **0.0080**，二次特征 CCA 是
**0.1157**，比值 14.5，却仍远低于合理的“高耦合”阈值。本报告对 funnel **全盲**；
二次 pilot 最多能说“高斯数没有描述这个几何”，不能把 0.1157 修饰成可靠的 `ρ*`。

## 八、度量纪律

这个包只报告局部几何，不替 Wave 2 做成本 argmin。以后若进入成本表，Kish ESS 与链
ESS 绝不能同场比较：前者衡量全图重要性权重，后者衡量链内自相关；计划中的实测是
SNIS 偏真值 1.40 个后验 sd、NUTS 偏 18.5 个，而 chain ESS 33 反比 Kish ESS 14
更大。一个共同 argmin 会选择离真相远约 13 倍的答案。
