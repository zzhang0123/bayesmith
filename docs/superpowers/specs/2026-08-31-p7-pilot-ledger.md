## 一、pilot 的裁决是非对称的

**只在 A3 会切换离开已发布默认、或差距落在噪声里时才跑**（`pilot_is_warranted`
是这两个布尔的合取，不是一次测量：pilot 不可达时代价就是零）。从已发布计划抽
一个短 pilot，在**同一批抽样**上算两次典型相关——一次线性特征、一次加平方项
——**报告比值**。

**它的职责不是给一个更好的 c。** pilot 的 ESS 支撑不了，而且那个数不可用。
本 checkout 实测（Neal's funnel：v ~ N(0,3)，x ~ N(0, exp(v/2))，Laplace 相关
精确 0.0，全部依赖都在二阶矩），20 万 iid 抽样：

| 量 | seed 0 | 20 个 seed 的范围 |
|---|---|---|
| 线性 cc | 0.007992 | 0.00055 – 0.01218（22 倍） |
| 二次 cc | 0.115687 | 0.1018 – 0.2389（2.35 倍） |
| 比值 | 14.48 | 8.36 – 292.1 |

另一次独立运行、不同特征构造，同一现象的二次 cc 记为 **0.619**——比这里最小的
0.1018 大 **6.08 倍**。**绝对值是估计器相关的，比值才是信号。**

零假设从另一侧确认这一点：联合高斯对（ρ=0.6，20 万抽样，20 个 seed），比值
落在 **[1.0000001, 1.0000508]**。没有东西给平方项发现时，平方项什么也不加。

裁决语义（`pilot_report` → `PilotReport.vetoed` → `resolve_switch`）：

* 二次 cc 同时越过 `sqrt(p_aug / N_eff)`（D102）**且**超线性 cc 一个声明的倍数
  （D101）→ **否决切换**，点名 funnel，**不提出任何替代**，`blind_to = ()`；
* 否则 → **没结论**，A3 的决定**照旧生效**（`resolve_switch` 原样返回调用者的
  proposal），报告 `blind_to = ("gaussian-only",)`。

**一个卡住的 pilot 代价为零，也不会静默变成抛硬币。**
`tests/dispatch/test_pilot.py` 里
`test_an_inconclusive_pilot_leaves_the_decision_exactly_as_it_was` 就是这条：
若没结论时 pilot 改成弃权（返回已发布默认），这个测试变红——因为那等于
**默默反转它被叫来看的每一次切换**。

实测裁决：seed 0 的 funnel 比值 14.48 > 7.0 且二次 cc 0.1157 > 0.004472
→ **否决**；20 个 seed **20/20 否决**。高斯零假设 **0/20 否决**。

## 二、对账账本

`Posterior` 加 `cost: CostReconciliation | None`。记录预测区间、实测 秒/ESS、
以及**哪个输入主导**。

**这个账本是即使其它每一部分都错了也仍然有价值的那一块**：它不依赖成本表达式
是对的，只依赖它们的输入被记下来了。每次运行的"预测/实测"对就是成本模型的
标定数据——这个包到现在一条都没有。

接法：`LadderRecord` 继续只带标量，并补齐余下的输入（κ_x、a、四个计时常数、
m），`recorded_inputs` 把它还原成 `LadderInputs`；`reconcile` 用**同一个**
`_rows` 取出**实际跑的那一行**（不是记分板的赢家——记分板不改路由，两者经常
不同，拿赢家的预测去对另一件事的实测是错的）。

主导归因是**分区**而不是敏感度：一行的预测被拆成三项，和为一，

    split：    (τ(c)−1)·(G+C)  +  G  +  C        G = a·√κ_cond·c_gθ，C = m·k_cg·c_A
    collapse： 0                +  G  +  C
    joint：    0                +  G  +  0

三项分别记为 `c`（Gibbs 放大——funnel 的位置）、`a`（leapfrog 标定不迁移的
位置）、`cg`（内层 CG）。**没有断言任何消去**：τ·(G+C) 只是写成
(τ−1)(G+C)+G+C，是同一个数。区间宽度 `width = hi/lo` 单独报告而**不设门**：
只声明了计时噪声时它恒等于 (1+t)/(1−t) = 1.2222，比这更宽就说明有未声明的
不确定度混进来了——"区间开得太宽"这条线索因此可读而不需要第四个阈值。

实测（`indirect_ancestor`，strategy="cost"，80 draws）：

    cost ledger [split]: predicted [0.00064116, 0.00078364] s/ESS (width 1.222x),
    measured 0.00933364 s/ESS from 0.806523 s at ESS 86.4104 | outside the
    interval | shares: c 0.000, a 0.007, cg 0.993 | dominated by cg

这条 fixture 上 ρ 读到 0.0，所以放大项份额精确为 0，99.3% 的预测是内层 CG 解。
**一次落空被定位到 cg，而不是 c、也不是 a**——这正是账本要做的事。

**已发布路径逐字节不变**：`strategy="declared"` 没有记分板，也就没有预测可对，
`Posterior.cost` 保持 `None`。`_reconciled` 是唯一的挂载点，且计时只括住采样
本身（`_dispatch_sample`），不把本模块的记账算进采样代价。

## 三、新增阈值（3 个，magic = 0）

- **D101 声明的倍数**（`pilot.DECLARED_MULTIPLE = 7.0`，derived）：比值须超过
  它才算平方项改变了答案。**被两个实测夹住，且刻意不拟合 funnel**：下界是
  估计器自身的任意性——同一 funnel 的二次 cc 在两种特征构造下读到 0.1018 和
  0.619，**6.08 倍**，低于这个倍数的比值分不清是曲率还是换了特征；上界是现象
  本身——20 个 seed 的最小比值 **8.36**，取到那里就否决不了它存在的理由。
  7.0 是 (6.08, 8.36) 里的整数。离零假设很远：高斯对的比值从没离开
  [1.0000001, 1.0000508]。float 格。
- **D102 抽样地板**（`pilot.quadratic_cc_crosses_floor`，derived）：
  `quadratic_cc > sqrt(p_aug / N_eff)`。有限样本下 p_aug 个特征与一个独立目标
  的最大典型相关不是零，而是这个量级。开边界：**正好在地板上**就是独立特征
  产生的东西，admit 它等于让 pilot 拿零证据否决。它在做实事——funnel 的**线性**
  读数 20-seed 最小值 0.00055 就落在 0.004472 的地板之下。float 格。
- **D103 主导份额**（`costs.DOMINANCE_SHARE = 0.5`，exact_or_domain）：
  `share > 0.5` 才点名一个输入。**一半是唯一不需要打破平局的值**：三项是一个
  分区，和为一，这样的分区里至多一项能超过一半，所以超过它时"哪个输入主导"
  只有一个答案。**在**一半上或以下，两项可以并列最大，那时点名任何一个都是
  编造归因——账本弃权（`dominant = ""`）并照样报告三个份额。float 格。

三个阈值都登记进 `tests/numerical_gates/registry.py`，各带两侧（tighten +
loosen）边界格与变异，两侧都能把冻结的 witness 变红。

## 四、这一段没有做、也不该顺手做的事

* pilot **不产出 c**。它只有否决权，没有提议权；这不是保守，是它的 ESS 与
  估计器散布不支持一个数（见 §一的两张表）。
* 账本**不裁决成本表达式对不对**。它记录预测与实测，让以后有数据可以裁决。
  `within=True` 的强度只等于 `width`——一个开得够宽的区间什么都满足。
* `_LEDGER_ROWS` 是**能力查表**而不是字符串比较（与 P6 修的
  `_PREDICTION_DEPENDENT_METHODS` 同一个理由）：以后新加的方法必须自己登记
  行名，否则它就没有行——那是一次响亮的缺席，而不是把实测悄悄记到错的预测上。
