## 一、两面坏在同一件事上:**在 DOMAIN 里做了 PARTS 的事**

复数 latent 的解在 G9 最小面就定了形状:每个复成员拆成 `(re, im)`,因为对一个
**实**预测,复系数到数据的映射是 **R-线性而非 C-线性**,而 JAX 对复输入给的是
**共轭**梯度。`real_parts` / `normal_operator` / `domain_zero` 都住在 parts 空间。

* `dense_operator` 用 `jax.jacfwd` 在**域**上求导 → 复数直接被拒。
  改成按 `_spans` 铺**实自由度**:`n` 个复条目占 **2n** 行,**实部半段在前**。
* `log_weight` 把 `delta = x - mu` 直接喂给 `normal_operator` → 形状在
  `jax.linearize` 里炸。改成先 `split`,并**按叶子求和**。
  > **拆的理由不是它报错了。** `x^T M x` 在 C 上根本不是 `q` 建立时用的那个二次型,
  > 所以哪天它不报错了,它就是**静默的错标量**。这句话写进代码注释里。

**对全实块逐比特不变**:`split` 对全实块是恒等,叶子还是同一批数组同一个顺序。
测试里**把旧写法重算一遍**来核对,而不是在 docstring 里声称。

## 二、追进稠密参照时,撞出一个 **0.4.0 就带着的缺陷**

`fisher_information(include_prior=True)` 原本这样加先验曲率:

```python
curvature = jnp.concatenate([
    jnp.reshape(1.0 / jnp.asarray(block.prior_std[name]) ** 2, (-1,))
    for name in block.names])
values = values + jnp.diag(curvature)
```

一个**标量** `prior_std` 配一个向量 latent:`reshape` 得长度 **1**,`jnp.diag` 得
一个 **1×1** 矩阵,`values + (1×1)` 于是**广播到每一个元素**——先验落在了**所有
非对角元**上。

**实测**(手搭 `(3,)` 块,`prior_std = 2.0`):

```
found:                         expected:
[[25.039  10.168   9.311]      [[25.039   9.918   9.061]
 [10.168  40.628 -16.545]  vs   [ 9.918  40.628 -16.795]
 [ 9.311 -16.545  29.800]]      [ 9.061 -16.795  29.800]]
```

对角**是对的**,矩阵仍然对称、有限、量级正常;每个非对角元多了 **0.25 = 1/2²**。

**它为什么活过了一次发布:图这条路够不到它。** numpyro 把 `Normal` 的 scale 广播到
batch 形状,所以 `linear_operator` 交出来的 `prior_std` 已经是满形状的,拼出来的
长度**碰巧**是对的(实测:图路线 `max|diff| = 0.0`)。手搭的块够得到;而**复数块
永远够得到**,因为那里实自由度是声明条目的两倍——**这就是它被找到的方式**。

**修法**:曲率改从 `variance_parts` 取——那是 `normal_operator` 读的**同一份**
拼写,所以稠密路线与迭代路线不可能对它有不同看法——并**逐 span 广播**,于是一个
既不是 1 也不是 latent 自身大小的宽度会**响亮地报错**而不是被绕回去或截断。

## 三、**D38**:`diagnose` 的复数拒绝**保留**,而这是一条裁决

G9 全量**没有**解除 `identifiability` / `prior_sensitivity` 对复 latent 的拒绝。
理由,以及为什么它不是漏做:

一个秩判决在 C 上**既不是 n 也不是 2n**。要让它有意义,得先回答一个**语义**问题:
一个 R^2n 里的零方向,对一个在 C 上声明的 latent 意味着什么、报给谁?——这个问题
本程序没有人回答过,而 D18 只裁了「复数是 bayesmith 的原生能力」,没有裁这个。

**保守的一侧是保留拒绝**:它指名、给理由、且**不阻塞任何别的东西**——同一张图照样
解、照样抽、现在还能出 Fisher。守卫钉的是**两个方向**:拒绝在,以及求解不受影响。
没有第二条,一个把整张图都拒掉的实现同样会绿。
