## 一、范围先收窄（最重要的一条）

**collapse 是小块专用特性，不是通用加速器。** 实测结论，不要重建成通用加速器：

* k=8 时 c ≳ 0.95 collapse 就赢；k=512 时要 c ≳ 0.9995 才赢。
* 截断 trace-log **不救大 k**：按标量阶数比 QR 慢 25–33%，按**认证阶数**慢
  **95–130%**（梯度误差 2.803e-06）。原因不是数值问题：ρ(X) 在每个 fixture
  上都是 0.85–0.93，m 要取 135–212 阶，上百次算子作用把"不物化矩阵"省下的
  钱全花掉。根因是 P = A·S·Aᵀ 相对 Λ = N **根本不小**，而没有有物理依据
  的通用 Λ selector（D83）。

collapse 路线物化稠密设计矩阵、每个梯度做一次 QR——这正是
exact/solve.py 存在的理由要避免的那一侧。它只在耦合强到 Gibbs sweep 的
τ(c) 放大超过这个代价时才值得；本模块**不做这个裁决**，costs.py 报告
数字，调用者选择。

## 二、实现（算术已验过，不要重建）

    unchecked_operator(probe_gaussian=False) → dense_operator → compress →
    SqrtInfo.combine(nuisance_prior) → marginalise_arrays

对稠密 slogdet oracle **1.8e-14**，梯度 **2.6e-08**，jit 与 hessian 干净。
sqrtinfo.py:277 折进 offset 的 −Σ log pivots[:n_block] **就是**
0.5·logdet(F_bb)，由执行消元的同一个 QR 产出。

execute.py 的 ladder 加**一个**臂 collapse：NUTS 打归约图上的边缘目标
（collapse_graph → reduce_with_evidence），然后对每个保留的 θ 做一次
vmapped gcr_sample 回抽。

**两个硬陷阱**：

1. 两处都必须用 unchecked_operator(..., probe_gaussian=False)——local_block
   以 probe_gaussian 默认 True 调 _env_before，jit 下从 exact/gaussian.py:249
   抛 TracerBoolConversionError。
2. traced pivots 上加 eqx.error_if：一个在链会到达的 θ 处无约束的块必须
   **抛出**，而不是返回一个有限的、看起来合理的数。地板是
   pivots[:n_block] > sqrt(eps)·max(pivots)（相对地板，derived），与
   sqrtinfo.marginalise 的急切拒绝同一把尺。

Posterior.diagnostics 对被精确回抽的那个块保持 None（遵守已有弃权语义）。

## 三、顺手修一个潜伏陷阱

execute.py:545 的 depends_on_prediction = plan.exact.method != "gcr" 是
**字符串比较**，任何新方法都会被读成 prediction-dependent。改成能力查表
_PREDICTION_DEPENDENT_METHODS = {"gcr+snis", "gcr+mh"}："gcr" 与 "log-gcr"
都在固定 sigma 下求解，只有 "gcr+snis"/"gcr+mh" 因 sigma 随 prediction 移动
而需要 GLS 不动点。

## 四、两个明确排除的东西

* **非中心化**：D23 实测这个声明层里一个 Latent 不能参数化另一个 Latent 的
  先验。重参数化是用户义务，解锁条件写在 D23。**不要实现它。**
* **campaign fold**（已修，2026-08-31）：campaign.py:91-93 以
  isolate(graph, names, {}) 构造设计，空 at 与零硬编码。本阶段**当时没有动它**；
  它后来作为独立修复落地在 `factorize`（不是 campaign.py）：campaign 折现在先
  用 `check_linearity` 拒绝「在 survivors + per_epoch 上非联合仿射」的图——
  这种图的 design 就是零点处的单个 jacobian，而非仿射时它描述的是点而不是模型
  （`mu = g * n` 实测：jacobian 全零、折叠结果是独立于数据的常数）。见
  `tests/marginal/test_campaign.py` 与 `tests/dispatch/test_streaming.py`。

## 五、测试

那条**绝对密度**双计数守卫（P4）已经存在且是硬的（7.105e-15 对 atol 2e-9），
**不要削弱它**。collapse 臂有自己的等价物：log_joint(归约图 ⊕ 证据项) 对
log_joint(原图) 在块上稠密积分，K 个点含每个参数的两个端点、**非单位**先验
宽度。

边界验证：在 c 的交叉点两侧**绕过调度器**，把 split 和 collapse 两条都跑到
固定 ESS（不是跑调度器——通过调度器测只能看到函数自身连续性，那是规则点名
的反模式）。c ∈ {0, 0.5, 0.99, 0.999}，k/κ 各跨四个数量级。
