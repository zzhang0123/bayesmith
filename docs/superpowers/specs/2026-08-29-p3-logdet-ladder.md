# P3 — logdet 阶梯：从可证明的特例到有证书的近似

本文是 P3 的唯一决策家，承接计划
[`2026-08-29-coupling-collapse-ladder.md`](../plans/2026-08-29-coupling-collapse-ladder.md)
的 M8。记

\[
\Sigma=\Lambda+P=(I+X)\Lambda,\qquad X=P\Lambda^{-1}.
\]

这里的 \(\Lambda\) 是调用方显式给出的预条件子；它不是被默认等同于噪声协方差的名字。
`check_logdet_premises` 只检查前提而不算行列式；调度从基例开始按顺序选择第一个已验证
前提。这样“不能走这条路”和“算出了一个数”始终是两个可区分的结果。

## D79 — 问题：在什么顺序和可检验前提下选择 logdet 方法？；裁决：采用有序基例加 1–8 级，首个满足且已验证的前提胜出，无法安全地满足前提的第 8 级明确拒绝。

| 顺序 | 方法 | 精度 / 结果 | 具体、可检查的前提 |
|---:|---|---|---|
| 0 | \(\Lambda\) 本身 | 精确 | \(\Sigma=\Lambda\) 逐元素精确相等。 |
| 1 | 低秩 Newton 终止 | 精确 | 给出代数因子 `LowRankFactors(left, right)`，它重构 \(P=LR^T\)，且其列数 \(k\) 同时不超过 `low_rank_max` 与 `low_rank_fraction*n`；对角紧凑输入以精确非零支撑给出阶数。 |
| 2 | 状态空间 / block-LDL 递推 | 精确 | 请求的块大小整除维数；越过相邻块的元素为零，并且 \(\Sigma\) 对称正定。 |
| 3 | 结构化精确式 | 精确 | 对角、circulant、Toeplitz 的实际条目满足结构检查，或 Kronecker 因子实际重构 \(\Sigma\)；再验证 SPD。标签不是证据。 |
| 4 | 稠密 Cholesky | 精确 | \(n\leq\) `dense_max_n`，\(\kappa(\Sigma)\) 严格低于该 dtype 的 `condition_ceiling`，且 \(\Sigma\) 对称正定。 |
| 5 | 有限 Newton 微扰 | 精确 | \(n\leq\) `finite_max_n`，或由代数证据得到的 rank \(\leq\) `finite_max_rank`。 |
| 6 | 截断 trace-log | 确定性近似 | 已验证的确定性 \(\operatorname{Tr}(X^r)\) 提供者覆盖固定阶数，给出的 \(\rho\) 没有低报实测谱半径，且 \(0\leq\rho<1\)。 |
| 7 | 冻结 Hutchinson trace-log | 确定性（对已冻结探针）近似 | 不可变 `FrozenProbes`、固定阶数、保守的严格 \(\rho<1\) 证书。其随机抽样误差/偏差不是第 6 级的解析精确迹承诺。 |
| 8 | 每调用重抽探针 | **拒绝** | 无论其它数值看似如何都拒绝：目标逐次变成带噪声的函数，破坏 HMC leapfrog 可逆性。 |

第 5 级的有限恒等式是

\[
\det\Sigma=\det\Lambda\sum_{j=0}^{n}e_j(X),\qquad
j e_j(X)=\sum_{q=1}^{j}(-1)^{q-1}e_{j-q}(X)\operatorname{Tr}(X^q),
\]

其中 \(e_0=1\)，例如
\(e_1=\operatorname{Tr}X\)、
\(e_2=\{(\operatorname{Tr}X)^2-\operatorname{Tr}(X^2)\}/2\)。第 6 级使用

\[
\log\det\Sigma=\log\det\Lambda+
\sum_{r=1}^{\infty}\frac{(-1)^{r+1}}r\operatorname{Tr}(X^r),\quad\rho(X)<1.
\]

单个标量特征方向的尾项公式**恰为**
`rho^(m+1)/[(m+1)(1-rho)]`。整条 trace/logdet 的证书必须再乘显式重数
\(N_{\mathrm{trace}}\)：
\(N_{\mathrm{trace}}\rho^{m+1}/[(m+1)(1-\rho)]\)。否则
\(X=\rho I_n\) 会少报整整 \(n\) 倍；标量界只能用于其明确说明的标量用途，不能冒充 whole-logdet 证书。

“作 \(m\) 次向量算子作用”并不从一般黑盒算子中决定精确
\(\operatorname{Tr}(X^r)\)：不同矩阵可以在那些向量上相同而有不同的迹。因此第 6 级要求精确 power-trace 或能验证地导出它的结构；冻结的随机迹估计属于第 7 级，绝不重命名成第 6 级。

边界套件以独立的 `np.linalg.slogdet` 对拍所有精确路，所有尺度均非单位；它覆盖
\(\rho\in\{0.01,0.5,0.9,0.99,1.01\}\)（1.01 及 1 都拒绝），直接调用阈值两侧的方法，并以紧凑对角 fixture 覆盖 \(n\)/rank
\(\{1,10,100,10000\}\)。没有分配 10000 方阵：这保留了前提检查的四个数量级覆盖，同时不把边界测试误变成资源测试。

## D80 — 问题：为什么低秩第 1 级不是另一套近似或 tolerance 分支？；裁决：它是第 5 级 Newton 恒等式在 rank \(k\) 的精确终止特化，代码共享同一 `_newton_logdet` 路径，测试在低秩输入上断言两公开入口逐位相等。

若 \(\operatorname{rank}(P)=k\)，则 \(\operatorname{rank}(X)\leq k\)，故 \(X\) 只有至多
\(k\) 个非零特征值。初等对称多项式每一项都取互异特征值的乘积，所以对 \(j>k\)，
\(e_j(X)=0\)；Newton 递推在 \(k\) 后精确终止。这正是行列式引理的同一代数事实，而不是第二个 determinant-lemma 实现。

这里“精确”不可替换成数值 rank tolerance。一个看似极小的 \(P\) 方向，经
\(\Lambda^{-1}\) 放大后可以是量级一；把它按容差丢弃便少掉真实的行列式因子。故稠密低秩证据要求因子对 \(P\) 的实际重构，紧凑对角路要求精确非零支撑；只有这些代数证据才许可早终止。

## D81 — 问题：哪些 logdet 近似可作为 HMC 的确定性目标？；裁决：确定性截断与冻结探针安全，每调用重采样一律拒绝，并将 eager 证书与 JAX runtime 内核分层。

截断有限和是 \(\theta\) 的确定性、可微函数；JAX 对这个截断对象直接求导即可。固定的 common-random-number 探针也令 Hutchinson 估计在运行时成为同一个确定性函数。相反，每次调用重抽探针会令相同状态有不同势能，leapfrog 不再可逆，因而绝不能进入 HMC 目标。

结构、rank、精确迹提供者和 \(\rho\) 的检查在 eager 的 NumPy 层完成。公开的
`make_trace_log_plan` / `make_frozen_trace_log_plan` 工厂把 warmup 证书所选 order
以及不可变探针绑定进只读执行计划；调用时只接收随 \(\theta\) 变化的数据，不能逐次降阶、
换探针或重抽探针。底层 `*_runtime` 内核是私有的纯 JAX 实现：它们没有 Python
收敛守卫、可 `jit` 且可微。精确迹证据逐位验证而非以 `allclose` 近似验证，因此公开的
analytic tail bound 不会漏掉另一个未计入的 provider tolerance。这不是遗漏检查，而是避免在
traced HMC 内伪造一个可运行的 \(\theta\)-依赖分支。

## D82 — 问题：\(\rho(X(\theta))\) 随参数变动时，如何不把一次局部检查说成全程保证？；裁决：warmup 探针集测最大值并加 margin 后选固定 order，运行时不检查，保留样本事后审计越界。

生命周期是：trace 外 warmup 在探测点测 \(\rho\)，取最大值加安全裕度，并以 whole-trace 重数界选最小固定 \(m\)；HMC runtime 只执行已证书化的固定内核；运行结束对 retained samples 复算 \(\rho\)，报告越界索引。运行中既不能可靠地做 Python 收敛判断，也不应把拒绝伪装为某个有限数。

文档与代码必须保留这句话的约束含义：**warmup rho certificate is, like solver `tol`, the only number between the user and silent error.** 它不是漂亮的诊断指标，而是用户与静默错误之间唯一的数值屏障；事后审计若失败，近似目标的适用声明也随之失败。

## D83 — 问题：谁选择 \(\Lambda\)，以及幂迭代能否给严格的 \(\rho\) 安全证书？；裁决：\(\Lambda\) 是显式的调用方预条件子设计，不引入无根据的通用选择器，且一般非对称 \(P\Lambda^{-1}\) 不接受下偏幂迭代估计作严格证书。

直接以前景扰动相对噪声 \(N\) 展开可能有 \(\rho\geq1\) 而发散；更贴近
\(\Sigma\) 的对角、块对角或 circulant \(\Lambda\) 可降低 \(\rho\)，这与 CG 预条件是同一设计问题，\(\Lambda\) 不必是 noise。

仓库可复用的是 `exact.conditioning` 的无矩阵谱迭代，以及 precision 类的结构化 action / log-normalizer；它们不是一个有物理依据的通用 \(\Lambda\) selector。`largest_eigenvalue` 的 SPD 幂迭代估计从下方逼近；而一般 \(P\Lambda^{-1}\) 可非对称，下偏估计会低报严格 \(\rho\) 并放行发散级数，不能作为安全证书。当前可验证的 dense/compact-diagonal 输入改以精确特征值/对角最大值测量，而非隐藏选择或不安全估计。
