# P5 — 只读成本记分板（dispatch/costs.py）

> **文档状态：`module-spec`** · 已发布模块/能力的当前设计文档，从属于顶层设计；改动对应代码须同步本页。索引见 docs/README.md。

**日期**：2026-08-31　**D 编号**：D93–D96　**probe**：probe_24

## 一、这个阶段做什么

Wave 2 里唯一不改任何路由的一步。compile(graph, strategy="cost") 测量
两块的 canonical coupling rho 与三个策略条件数，打印一张 split / collapse /
joint 三行的记分板——告诉用户模型为什么混合得差、collapse 能帮多少，而
不改任何已发布路径。默认 strategy="declared" 与 costs.py 存在之前逐字节相同。

## 二、三个成本表达式

    k_cg(kappa, tol) = ceil(0.5 * sqrt(kappa) * log(2 / tol))
    tau(c)         = (1 + c^2) / (1 - c^2)

    C_split    = tau(c) * [ a*sqrt(kappa_cond)*c_gtheta + m * k_cg(kappa_x, tol_x)*c_A ]
    C_collapse = a*sqrt(kappa_marg)*c_gc + k_cg(kappa_x, tol_x)*c_A
    C_joint    = a*sqrt(kappa_joint)*c_g_all

m 为 1（gcr / gcr+snis）或 3（gcr+mh）。kappa_cond / kappa_marg / kappa_joint
来自 diagnose.coupling.block_coupling 实测；kappa_x 是精确块自身的条件界
（plan 的 kappa）；rho 是最大 canonical correlation。

## 三、三条硬约束（每条都被实测逼出来）

1. 不得断言任何消去。CG 项在 split 分子出现 tau*m 次、在 collapse/joint
   各一次，不约掉——split_cost / collapse_cost / joint_cost 各自把 CG 项拼写完整。
2. c 上没有闭式交叉点。kappa_marg 不是 c 的函数（F_tt=diag(1,100) 与
   diag(100,1) 在同一个 c=0.99 下真实 κ(Schur) 分别是 5025 与 1.99，而
   κ(F_tt)/(1−c²) 两次都说 5025，差 2525 倍）。交叉点只能数值求解。
3. c_gtheta / c_gc / c_A 直接计时测，不建模。grad/(A+Aᵀ) 的比值在两个
   fixture 上随 n 朝相反方向变化；它们是输入（TimingConstants），不是图大小的函数。

## 四、argmin 与弃权

赢家 = 最小 cost_hi；任何 cost_lo < winner.cost_hi 的行，或相对差距小于
CONTESTED_BANDWIDTH 的行，标 contested。a 进入全部三个 HMC 行，无法在它们
之间区分——这句话印在记分板上。

任何 +inf 输入使该行不能赢；全部 +inf 时弃权，compile() 落到今天的行为，
str(plan) 逐字节不变（LadderRecord.line() 返回空串）。

## 五、那个必须写进设计的度量陷阱（D96，policy）

execute.py 的 _collapse_reason 记录：plated_radiometer(n=25, κ=0.4)、N=1200
时 SNIS 偏真值 1.40 个后验 sd，NUTS 偏 18.5，而 NUTS 的 chain ESS(33) 超过
Kish ESS(14)——以 ESS 计价的目标函数会选中离真相远 13 倍的答案。

规则：绝不把 Kish ESS 与 chain ESS 放进同一个 argmin；全图行绝不与链行同场
比较。记分板因此只比较 COST，从不读 ESS，且每行携带 CostRow.kind
（"chain" / "whole-graph"）把两种 ESS 货币留在各自的比较里。

## 六、新增阈值

- D93 CONTESTED_BANDWIDTH = 0.25（derived）：gap_is_contested 的 gap < 0.25，float 格。
- D94 TIMING_NOISE_TOLERANCE = 0.10（derived）：timing_noise_in_domain 的 tol < 1.0，float 格。
- D95 K_CG_TOL = 1e-3（derived）：cg_tol_positive 的 tol > 0.0，exact 格。
- D96 ESS 分离规则（policy，static，无边界格）。

三个数值阈值全部登记进 tests/numerical_gates/registry.py，各带两侧
（tighten + loosen）边界格与变异。magic 个数 = 0。

## 七、接口

compile(graph, *, key=None, strategy="declared"|"cost" = "declared", a=1.0, timing=None)。
InferencePlan 增加 ladder: LadderRecord | None（eqx.field(static=True)，全标量 +
指纹，不持 numpy 数组）。str(plan) 在与 streaming 相同的 guard 下追加
ladder.line()，弃权时为空串，str(plan) 逐字节不变。
## 八、P7 在这个模块上加了什么（2026-08-31）

LadderRecord 继续只带标量，并**补齐余下的输入**（kappa_x、a、四个计时常数、m），
使 recorded_inputs 能把它还原成 LadderInputs——账本的全部主张就是"输入被记下来了"。
新增 D103 DOMINANCE_SHARE = 0.5（exact_or_domain，share_is_dominant 的
share > 0.5，float 格），以及 CostReconciliation / reconcile / cost_shares /
dominant_input / relative_width。细节与实测见
docs/superpowers/specs/2026-08-31-p7-pilot-ledger.md §二、§三。

记分板本身**未改**：argmin、contested、弃权、str(plan) 的逐字节不变性都不受影响。
