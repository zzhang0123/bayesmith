## 〇、为什么先做 G2

交接页与计划都把它列为**并行候选**:Wave B 的先决,D7 与 D11 共同指向的
gradient-MAP 出口,在 bayesmith 一侧、不受发布门约束。D7 的裁决文本逐字写着
它的第二个后果:「Wave B 的先决因此**确实含 G2**(`bayesmith.fit` 承接
gradient-MAP 出口,今日 bayesmith 无对应物)」。

开工先读了两侧的既有形态:

* rheplicant `calibrate.py`:`GradientCalibrator` / `AdamCalibrator`,
  `fit(forward, params0, observed, loss_fn)` —— 目标是 **loss(预测, 数据)**,
  外加两条入口守卫(形状、**loss 方向**)。
* rheplicant `engines.py::gradient_estimate`:Adam over 一个**条件势能**,
  **逐 latent 步长**(`learning_rate * _magnitude(latent)`),固定步数,
  返回 `(values, 达到的势能)`,**没有收敛判据**。

两者的差异不是风格:`engines.py` 自己的 docstring 逐字写着,`AdamCalibrator`
「minimizes `loss_fn(forward(params), observed)`,一个只看得见预测与数据的目标,
而条件后验是它与一个先验项的和,而这个接口没有办法传先验」。

**所以 G2 的表面必须是两个而不是一个**,这是本页的第一条设计裁决(§五)。

## 一、交付了什么

`src/bayesmith/optimize.py`,六个公开名(全部经 `bayesmith.__init__` 的惰性表导出):

| 名字 | 是什么 |
|---|---|
| `fit(graph, at=None, *, names=None, ...)` | 图入口。**最大化 `log_joint`**;`names=None` 是联合 MAP,`names=(...)` 是**块坐标**(其余按 `at` 冻住) |
| `minimize(objective, at, *, ...)` | 优化器本身,任意标量目标。Wave C 的 calibrator 打分的是**预测对数据**,不是一个联合 |
| `Fit` | `values` / `objective` / `history` |
| `check_loss_sense(loss_fn, predicted, observed)` | 方向守卫(D11「随迁」的那条) |
| `MINIMIZE` / `MAXIMIZE` | 方向词汇,**导出**,这样门面不留第二份拼写(D16 「常数自 bayesmith 导入」的同一条) |

方法两个:`"adam"` 与 `"gradient"`;**逐 latent 步长** `step_sizes=`(在各自的
单位里)。`steps` 步就是 `steps` 步,**没有提前停止,也没有收敛判据**——判据由
知道容差的那一层给,这与 exact 路径自己的分工一致(`iterative_gls` 返回
`converged` 字段而把提升留给调用方)。

## 二、§四式五节记录

### (1) fixture

**全部复用 `tests/exact/models.py` 的既有模型**,一个新造的也没有,除了
`TestPerLatentStepSizes` 里那个刻意「两个 latent 差 1e4 倍」的小模型
——它演示的性质(单一步长服务不了两套单位)在既有模型里没有对应物。

`straight_line`(单 latent 共轭)、`two_linear_latents`(两个 latent,**设计正交**)、
`collinear_pair`(两个 latent,**数据只定住 a+b**)、`radiometer(kappa=0.3)`
(σ 跟着预测走 —— D7 的那个模型)。

### (2) 数值一致

这一项**今天还没有对面**:rheplicant 侧没有任何东西委托到这里(Wave B/C 才接线),
所以「两包一致」在本批**不存在**,写清楚以免被读成漏做。本批能做而且做了的是
**与解析解一致**,见 (4)。

一条**跨路线**的一致仍然可查,而且查了:同一个共轭图,`fit` 的下降与
`wiener_solve` 的直接解在 float64 下逐 latent 相对一致到 **1e-3**(测试
`test_two_latents_land_where_wiener_solve_puts_them`)。这是两条**不同算法**,
不是两份实现。

### (3) 拒绝一致

同样没有对面。本批新增的**七条拒绝**逐条给出:

| 拒绝 | 为什么它必须是拒绝而不是返回 |
|---|---|
| 未知 `method=` | 落到默认分支会**静默换算法** |
| `steps` 非正整数 / `learning_rate` 非正 | `not > 0` 而不是 `<= 0`,**NaN 才会被拒**(NaN 与一切比较为假,而一个 NaN 步长会在第一步把所有参数变成 NaN) |
| **复数起点** | `jax.grad` 对复点给的是**共轭**梯度,减它走反方向——**不报错、不出 NaN、loss 历史看起来正常** |
| `step_sizes` 指名一个不在移动的参数 | 最可能的成因是 `names=` 与 `step_sizes=` 写的是两个不同的块 |
| `names` 指名一个非 latent / `names=()` / 图里没有 latent | 三条各自点名 |
| **结果非有限**(`eqx.error_if`) | 见 §三 |
| `check_loss_sense` 的三条(声明的、测量的、非有限的) | 见 §四 |

「结果非有限」用 `eqx.error_if` 而不是 Python `if`,与 `wiener_solve` 同一机制、
同一理由:jit 下 Python 的 `if` 不能对 traced 值分支。挂在**点**上而不是挂在
objective 上——调用方先读的是点,而一个没人用的检查可能被优化掉。

### (4) 独立 oracle

这一节是本页的主体。一个优化器的答案有**三种**互相独立的对照,三种都用了:

1. **纯算术**(不微分任何东西)。单 latent 共轭模型的 MAP 就是
   `(P0 mu0 + Σ x d/s²)/(P0 + Σ x²/s²)`,在 numpy 里算。
   `test_one_latent_lands_on_the_conjugate_formula`,rel **1e-4**。
2. **另一个算法**。`wiener_solve` 直接解正规方程,`fit` 迭代下降;两者只共享
   那张图。`test_two_latents_land_where_wiener_solve_puts_them`,rel **1e-3**。
3. **暴力网格**(不微分任何东西)。exact 路径解不了的模型——`radiometer`——用
   20001 点的网格取真目标的最小点。`test_the_fit_lands_on_the_grid_minimum`,
   abs **2e-3**。

**每一条都配了反空洞子句**,因为三条都能被一个什么也不做的实现满足:

* 前两条:`test_it_is_not_just_returning_the_prior_centre`。一个**零步**的 `fit`
  返回先验中心,而在数据与先验一致的模型上那几乎就是答案;这里先验中心 0.0、
  真值 2.5,「没动」与「收敛了」相距四个先验 σ。
* 第三条:`test_the_full_density_optimum_is_not_the_gls_one`。见 §三。

### (5) 有意的差异

* **`minimize` 与 `fit` 是两个入口而不是一个**(§五的裁决)。
* **没有收敛判据**,而 exact 路径有。刻意:`steps` 步就是 `steps` 步。
* **`step_sizes` 需要名字,一般 pytree 只有一个步长**。不是「限制装成规则」——
  逐 latent 步长之所以逐 latent,正因为 latent 带着**不同的单位**,而一个没有
  名字的 pytree 里没有东西供调用方把单位挂上去。
* `_magnitude`(把声明的尺度换成步长)**留在 rheplicant**:那是声明层的知识,
  bayesmith 收的是算好的 `step_sizes`。铁律 1 的私名普查已把 `_magnitude` 记为
  engines 在用的保持面。

## 三、D7 在这里被兑现,而它需要一条反空洞子句才有意义

`fit` 的目标是 `-log_joint`,**全密度**:`Σ log σ` 与声明的 `joint_prior` 都在里面,
而那也正是 `to_numpyro` 采样的那个密度。D7 (a) 要的就是这个。

**但「落在网格最小点上」这条测试,对一个丢掉 `Σ log σ` 的实现同样会绿**,只要
两个最优点碰巧重合。所以配一条:把对数行列式项**减掉**再扫一次网格,两个最优点
必须分得开。

减掉而不是重写:对角高斯的 `-log_joint` 里就带着 `Σ log σ`,所以
`gls_only = -log_joint - Σ log σ`。**在测试文件里把卡方重写一遍**,会让这个文件
里的一个笔误伪装成它正要测量的那个差异。

## 四、方向守卫:声明的一半与**测量**的一半

从 rheplicant 的 `_refuse_a_score_the_optimizer_would_walk_away_from` 移过来,
措辞与两半结构保持。它记录的那次实测照抄进 docstring(一参数增益拟合,真值 1.0):

```
mean_squared_error       ->  g = +0.9999    loss  2499  ->  0.002617
GaussianLikelihood(0.05) ->  g = -30.7349   loss -3.2e7 -> -1.3e11
```

两次运行的 loss 历史**都单调下降**,而那是调用方唯一的证据。

**声明的一半是白名单,而白名单对它没见过的代码恰好是错的**;测量的一半在方向
无歧义的点上打分——**完美预测** `loss_fn(observed, observed)`。误差在那里取最小,
对数密度在那里取最大。测试里那条**裸 lambda** 就是声明的一半够不到的那个。

异常类换成 bayesmith 的 `StructureError`(rheplicant 用 `ParameterSpaceError`);
Wave C 接线时门面负责翻译回来,这是 P1 `translate` 的既有职责,不是新东西。

## 五、两条本批自定的裁决,登记为 **D32**、**D33**

见计划 §二。摘要:

* **D32 — `fit` 与 `minimize` 是两个入口。** 一个把 calibrator 的
  「loss(预测, 数据)」硬塞进图,等于为一次最小二乘发明一个模型;一个只有
  `minimize` 的表面,则要 Wave B 的每个梯度块自己拼 `-log_joint`,那是把一句
  声明抄进每个调用点。两个入口**共用一个优化器**,所以不是两份实现。
* **D33 — 非有限的结果**是拒绝,不是返回值。

## 六、三件实测,每一件都改了代码或测试

1. **`two_linear_latents` 的两个 latent 是正交的**,因为它的设计是
   `linspace(-2, 2)`,`Σx = 0`。于是「冻住一个会改变另一个的最优点」这条反空洞
   子句在那上面**是空的**——实测差 **1.2e-07**。换成 `collinear_pair`
   (数据只定住 `a+b`)才有得比。**这条是测试自己抓出来的**,不是审出来的。
2. **朴素梯度下降与 Adam 不接受同一个步长**,而这是算术不是口味。
   本模型曲率 **L = 231.1**,稳定界 `2/L` = **0.00865**:0.006 收敛,0.02 给
   **NaN**;Adam 两个都收敛。一个只改 `method=` 不改 `learning_rate=` 的调用方
   正好落在这里 —— 所以非有限的结果被**拒绝**而不是当作一次拟合交回去(D33)。
3. **起点是承重的。** `radiometer(kappa=0.3)` 在先验中心 `w=0` 处
   σ = floor = 1e-3 而残差是 9 量级,目标值 **4.3e8**,最优处 24.2。
   从那里出发的 **6000** 步 Adam 走了 **0.08**,哪也没到,而 loss 历史**全程
   单调下降**。从 `w=1` 出发 4000 步就到。
   **这不是一个要靠把优化器写聪明来修的缺陷**,这就是 `at=` 的用途;
   写成一条测试(`test_the_prior_centre_is_a_cliff_on_this_model_and_at_is_the_remedy`)
   而不是一句注释,因为它同时钉住了「历史单调下降不等于到了」。
