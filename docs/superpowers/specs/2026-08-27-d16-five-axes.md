## 〇、先说清楚这不是在裁什么

D16 不是「谁的探针更好」的整体投票。**每条轴可以分别拍**,因为它们各自决定
不同的东西,代价也不同。三个可选形态,全文统一简称:

- **R** — 采 rheplicant 今日的语义(必要时 bayesmith 加兼容旋钮)。
- **B** — 采 bayesmith 今日的语义(rheplicant 侧改;**部分今日通过的模型将新拒**)。
- **K** — 两者并存,由一个**有文档的旋钮**选择,默认取其一。

**一条硬约束**(铁律 1):`check_linearity` 是 rheplicant 的公开名字,**签名、
异常类身份与被钉文案是保持面**。所以「采 B」在轴 1/2/3/5 上指的是**判据**改
变,不是把函数换掉;轴 4 的形状本身受这条约束直接管辖,见该节。

**每条轴的实测都配了一个「翻转」**:只动那条轴对应的旋钮,判决就反过来。没有
翻转的差异只是描述。

## 轴 1 — 锚点:`max|init|`(rheplicant)vs 先验宽度(bayesmith)

**问题**:「一倍探针」是相对什么量级说的?

**fixture**:`signal + 1e-7 · signal²`,`max|init| = 1.0`,先验宽 `100.0`。
默认 scales `(1e-3, 1, 1e3)` 于是让 rheplicant 最远探到 **1e3**,bayesmith
探到 **1e5**。

| | 判决 | 数字 |
|---|---|---|
| rheplicant | **accepted** | 1e-3x→0、1x→7.24e-8、1000x→8.24e-5(rtol 1.19e-3) |
| bayesmith | **REFUSED** | `AffinityRefused` |

**翻转**:把 rheplicant 的 scales 乘以两个锚点之比(×100),它**立刻拒绝**。
所以两侧的判据没有分歧,分歧在**探到哪里**。

**值得注意**:rheplicant 自己的 docstring 已经写着这条的失效模式——
「an all-zero ``init`` has no scale to take, so it falls back to 1.0 and the
probes become absolute……otherwise the sweep never reaches the regime the
sampler will actually explore」。零 init 是**常见**声明(零天空、零残差),
所以这不是边角。

**选项**:

- **B(建议)**:锚在先验宽度。理由是先验就是采样器将要去的地方,而 `init`
  是一个起点;零 init 的退化情形随之消失。**代价**:先验远宽于 init 的模型会
  被探得更远,今日通过者可能新拒(数量需实现后实测)。
- **R**:保持 `max|init|`,bayesmith 加旋钮。**代价**:把上面那条已写下的
  失效模式永久化。
- **K**:`anchor="init"|"prior"` 旋钮,默认取一。**代价**:两种语义都要长期
  维护,而两边的 fixture 会各自沉淀在自己的默认上。

## 轴 2 — at 点数:1(rheplicant)vs 3 含先验抽取(bayesmith)

**问题**:「给定块外 latent 时仿射」——给定它们的**哪些**值?

**fixture**:`signal + 1e-3 · (w − 2.0) · signal²`,而 `w` 的**声明 init 恰是
2.0**,先验是 `N(2.0, 1)`。也就是说:在声明点上**精确仿射**,离开就弯。

| | 判决 | 数字 |
|---|---|---|
| rheplicant | **accepted** | 三个 scale 全是 **0.0**——精确仿射,毫无余地 |
| bayesmith | **REFUSED** | `AffinityRefused` |

**翻转**:给 rheplicant `at={"w": 3.0}`(bayesmith 也会看的那类点),它**拒绝**。

**这一条与你自己的方法论直接对上**:`boundary-validation.md` 写着「a probe
that only tests 'moderate' parameters can miss them……ALWAYS include extreme
parameter values」。bayesmith 的 `at_points=` docstring 也点名引用了同一份
规则:「Passing a single point is how a check becomes a moderate-parameter
probe, which is the failure mode ``boundary-validation.md`` exists to
prevent」。

**选项**:

- **B(建议)**:默认 `at` + 2 个先验抽取。**代价**:探针成本 ×3;只在声明点
  仿射的模型将新拒——而那正是这条要抓的东西。
- **R**:保持单点。**代价**:与 boundary-validation 的规则相抵。
- **K**:`at_points=` 旋钮,默认 1 或 3。**代价**:默认值就是实际语义,旋钮
  只是把裁决推给每个调用点。

## 轴 3 — 判据数:单条相对(rheplicant)vs 相对 + σ 加权(bayesmith)

**问题**:「小」是相对**什么**说的——信号,还是噪声?

**fixture**:`signal + 1e-7 · signal²`,departure 在**每个探针**上都低于相对
容差,所以第一条判据放行。能反对的只有噪声。

| σ | rheplicant | bayesmith |
|---|---|---|
| 1e2 | accepted | accepted |
| 1.0 | accepted | **REFUSED** |
| 1e-2 | accepted | **REFUSED** |
| 1e-4 | accepted | **REFUSED** |

**rheplicant 在四个噪声档给出同一个判决,这本身就是这条轴**:它的签名里没有
噪声,合约**表达不出**这个问题。**翻转在 bayesmith 内部,只由 σ 驱动**——模型、
探针、departure 一动不动。

**是哪条判据越的线,从载荷读出来**(`AffinityRefused` 自 G11 起带两栏):

```
rtol=1.192e-03  weighted_rtol=1.000e-03
   0.001x  relative=0.000e+00  weighted=0.000e+00   fired: neither
       1x  relative=0.000e+00  weighted=0.000e+00   fired: neither
    1000x  relative=0.000e+00  weighted=6.262e-02   fired: sigma-weighted
```

**这与 D17 第一族是同一个结构性形状**:rheplicant 的探针入口只拿到模型描述
**预测**的那一半。D17 的对数轴已按 (b) 补上噪声;这条轴问的是要不要对**仿射**
检查也这么做。

**附带的第四条子问题:`Unresolved`。** bayesmith 在「算术精度不足以裁决」时
既不放行也不拒绝,而是标记并**警告一次**。它自己量过把 unresolved 记作拒绝
的代价:float32 下 `roundoff_stress` 10 个比值里红 **5** 个、
`test_a_true_claim_with_real_roundoff_passes_at_any_offset_ratio` 4 个参数里红
**3** 个,而那些模型的 `linear_in` 声明**是真的**。所以 bayesmith 选择
「接受并声明」。rheplicant 没有对应物。

**选项**:

- **B(建议)**:`check_linearity` 接噪声,加 σ 加权判据 + `Unresolved` 标记。
  **代价**:签名扩宽(新增关键字,不破坏既有调用);今日通过者将新拒——正是
  「相对信号很小、相对噪声很大」的那一类,而那类恰是共轭解会出错的地方。
- **R**:保持单判据。**代价**:一个共轭求解会把「远小于信号、远大于噪声」的
  曲率当成线性,而这正是它最容易出错的方向。
- **K**:噪声可选;传了才加第二条判据。**与 D17 (b) 的形状一致**,也是我在
  D17 里对「不传时怎样」采用的处理:不传则保守 + 出声。

## 轴 4 — 返回 / 异常形

**问题**:调用方在两条分支上各拿到什么?

| | 通过分支 | 拒绝分支 |
|---|---|---|
| rheplicant | `{scale: departure}`,**一层** | `LinearityRefused(errors, failed, rtol)` |
| bayesmith | `{at_point: {scale: departure}}`,**两层** | `AffinityRefused(at, errors, failed, names, rtol, weighted, weighted_rtol)` |

**这条轴与其他四条不同类**:它不决定任何模型的判决,它是**公开合约**。而铁律 1
说得很直白——公开名字、签名、异常类身份、被钉文案**保持**。所以:

- **rheplicant 的形状是保持面,不动。** 适配器负责把 bayesmith 的两层降成一层。
- G11 已经把这条路铺好:`AffinityRefused` 现在带 `errors`/`rtol`/`failed`,
  与 `LinearityRefused` 逐字段对得上;`weighted`/`weighted_rtol` 是 bayesmith
  独有的第二判据,**不经门面漏出**(与「不把独有能力经门面漏出」同一条)。
- **要拍的只有一件**:两层降一层时,at 点怎么合并。选项:(i) 取逐 scale 的
  **最坏** at 点(保守,信息有损但方向安全);(ii) 门面多一个可选返回形。
  *建议 (i)*——(ii) 就是拓宽门面。

## 轴 5 — 聚合粒度:整输出 max(rheplicant)vs 逐元素(bayesmith)

**问题**:一个暗通道里的谎言,旁边站着一个明亮而诚实的通道——看得见,还是被稀释?

**fixture**:六个通道在 **1e8** 量级、精确仿射;另六个在 1x 量级、带 `1e-2` 的
二次项。整输出的最大值由亮的那一半决定。

| | 判决 | 数字 |
|---|---|---|
| rheplicant | **accepted** | 1e-3x→**2.81e-14**、1x→2.18e-11、1000x→1.58e-7(rtol 1.19e-3) |
| bayesmith | **REFUSED** | `AffinityRefused`,逐元素 |

**翻转**:把亮的那一半拿掉,**同一个谎言**单独放着——rheplicant **拒绝**
(`LinearityRefused`)。所以它**看得见**这条曲率;藏住它的是「最大值取遍整个
输出」,亮的那一半同时决定了 departure 和 variation,比值因此塌成 1e-14。

计划预告过这条(「1e17 亮叶旁的 1e-2 假 linear_in 报 2.57e-14 通过」);本次在
1e8 亮度下实测得 **2.81e-14**,同一个量级、同一个故事。

**这是五条轴里正确性论证最直接的一条**:一个前景在 K、信号在 mK 的模型,正是
这台仪器的日常。

**选项**:

- **B(建议)**:逐元素判据 + 逐元素 roundoff 地板。**代价**:宽动态范围模型
  会更常撞上「算术精度不足以裁决」,这正是轴 3 的 `Unresolved` 存在的理由——
  两条轴因此**建议同批拍**,单独采 B 而不带 `Unresolved`,会把 bayesmith 已经
  量过的那些真声明变成红的。
- **R**:保持整输出 max。**代价**:上表第一行。
- **K**:旋钮。**代价**:默认值就是实际语义。

## 汇总:五条轴,请逐条拍

| 轴 | 差异 | 实测后果 | 建议 |
|---|---|---|---|
| 1 锚点 | `max|init|` vs 先验宽 | 零 init 时探针变绝对;rheplicant 自己的 docstring 已点名 | **B** |
| 2 at 点数 | 1 vs 3 含先验抽取 | 只在声明点仿射的模型报 **0.0** 通过 | **B**(与 boundary-validation 一致) |
| 3 判据数 | 单 vs 双(+`Unresolved`) | 四个噪声档同一判决;合约表达不出这个问题 | **B**,形状照 D17 (b)(噪声可选,不传则保守+出声) |
| 4 形状 | 一层 vs 两层;两个异常类 | 不决定判决,是公开合约 | **R**(铁律 1),只拍两层降一层时**取最坏 at 点** |
| 5 聚合 | 整输出 max vs 逐元素 | 1e-2 的谎言报 **2.81e-14** 通过 | **B**,**与轴 3 同批**(否则真声明变红) |

**若 1/2/3/5 全取 B**,D17 遗留的两例(边界仿射=轴 1,亮暗混合=轴 5)自动结清,
Wave A 的 D16 先决随之解除。

**代价的那一半我没有替你估**:「今日通过者将新拒」的**具体数量**要等实现后才
能实测,我不想在这里写一个没量过的数字。哪几条轴拍了 B,我就先实现再把新拒清单
逐条量出来交回。
